The seal & the icon set

The mark is a perforated seal: a solid ink disc of approval inside a dashed ring — the permission boundary. The whole icon language follows the same grammar: solid strokes are the thing itself; dashed strokes are the limits around it.

03 · Rules of the language

  • Solid stroke = the object (an agent, a receipt, a task).
  • Dashed stroke = a limit you set (caps, expiry, the pseudonym boundary). Dash rhythm is always ~3 on, 2.5 off.
  • 24px grid · 2px stroke · square terminals, matching the sharp print corners everywhere else.
  • Ink by default; allow-blue for interactive, green for verified, red for blocked/revoked. Never more than one color per icon.
  • The seal never rotates, but stamps (REVOKED, PROOF VERIFIED) always sit at a slight tilt.
